# Maintainers

FabricOps maintainers are responsible for reviewing changes, guiding releases,
and keeping the project aligned with its LF Decentralized Trust Labs scope.

## Current Maintainers

- [Pereowei Daniel](https://github.com/dpereowei)

## Maintainer Expectations

- Keep changes Apache 2.0 licensed.
- Require DCO sign-off on commits.
- Prefer feature branches and pull requests for project changes.
- Keep release artifacts, install docs, and sample image references in sync.
- Encourage collaboration with adjacent Hyperledger Fabric deployment and
  operations projects.
